# Homebrew tap

```
brew install pierre-borckmans/tap/clove
```

[clove](https://github.com/pierre-borckmans/clove): copy-on-write git worktrees with dependencies already installed. macOS and Linux.

`Formula/clove.rb` is rendered by clove's release workflow on every tagged release. Edit `packaging/homebrew/clove.rb.in` in the clove repo instead.
